Tambahan yang ditemukan saat verifikasi dan langsung diperbaiki:

- Rumus warna teks chip semula memilih teks gelap untuk biru/hijau (3,3:1). Rumusnya dikoreksi agar membandingkan dengan luminans `#1F2733`.
- Daftar "Belum absen" yang bisa digulir belum bisa difokus keyboard. Sekarang ditambah `tabindex="0"` dan label.
- Satu teks panjang di halaman Mesin meluber di 390px. Sekarang ditambah `overflow-wrap: anywhere`.
- Menu sel jadwal bentrok dengan penangan keyboard Bootstrap dropdown (5 error konsol). Sekarang memakai komponen sendiri.
- Riwayat pegawai sekarang ikut menampilkan hari kerja tanpa catatan, lengkap dengan tombol "Ajukan klarifikasi" yang mengisi tanggal otomatis.

## Bukti verifikasi

- `npm test`: 26 lolos, 0 gagal (termasuk test baru untuk unggah, tampil, tolak SVG, dan hapus logo).
- Uji wajah di browser (Chromium, kamera simulasi): pendaftaran wajah, kiosk mengenali pegawai, wajah asing ditolak, absen dinas luar terkirim, dan verifikasi wajah orang lain ditolak.
- 25 halaman (admin + pegawai) diperiksa di 1280 px dan 390 px: **0 pelanggaran axe-core WCAG 2 A/AA**, 0 overflow horizontal, 0 target sentuh di bawah 44px di 390 px, 0 error konsol. Halaman 820 px juga diperiksa untuk overflow.
- Klik-satu-per-satu (36 langkah, semua lolos):
  - Login kosong menampilkan validasi, login salah menampilkan pesan, login benar masuk ke `/admin`.
  - Tab pertama menampilkan "Lewati ke konten".
  - Dropdown Absensi terbuka dan tertutup dengan Escape.
  - Grid jadwal: panah memindahkan fokus, Enter membuka menu, Escape menutup dan mengembalikan fokus, memilih Libur lewat keyboard tersimpan dan tetap ada setelah muat ulang.
  - Modal "Atur banyak sekaligus" terbuka dan tertutup dengan Escape.
  - Panel filter terbuka di desktop dan terlipat di HP. Filter Terlambat diterapkan, dan filter tanpa hasil menampilkan empty state dengan aksi.
  - Ekspor Excel menghasilkan unduhan `.xlsx`.
  - Hapus pegawai menampilkan konfirmasi, dan Batal tidak menghapus.
  - Impor scan menonaktifkan tombol dan menampilkan "Mengimpor scan...".
  - Unggah logo menampilkannya di navbar, hapus logo mengembalikan nama saja.
  - Tombol Menu di HP membuka dan menutup navigasi.
  - Kelima tab navigasi bawah menuju halaman yang benar dan ditandai aktif.
  - "Ajukan klarifikasi" dari riwayat mengisi tanggal di formulir.
  - Menu Akun berisi Keluar, dan Keluar membawa ke halaman masuk.
